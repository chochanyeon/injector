# T-400 · 웹에서 실행·검증 및 결과 확인

**[English](T-400.md)** · 한국어 · [작업 인덱스](../index.ko.md)

## 설계

프로젝트와 레지스트리 선택을 쉽게 확인할 수 있게 한다. 실행 상태와 선택한 앱의 의존성 그래프를 보여 주고 세부 정보에 바로 접근하게 한다. 스위트 사전 점검과 실행은 CLI와 같은 Verifier 로직을 사용한다. 좁은 화면과 데스크톱에서 레지스트리 편집, 환경 준비, 스위트 실행을 확인한다.

## 개발

- [대시보드](../../injector_core/web/index.html)는 프로젝트 선택, 실행 현황, 의존성, 검증을 구분한다. 그래프는 선택한 앱을 기준으로 열리고 전체 앱으로 전환할 수 있다.
- [웹 서버](../../injector_core/web.py)는 CLI와 같은 스위트 점검과 실행 로직을 사용한다. 증거는 `.local/verification/`에 저장한다. 화면에서 항목별 판정을 확인하고 보고서 경로를 복사할 수 있다. 같은 서버와 프로젝트에서 새로고침하면 최근 스위트를 복원한다.
- 좁은 폭에서도 Registry 모달의 편집 영역과 검증·저장 버튼을 볼 수 있다. 터치 화면에서는 편집 영역을 누를 때 키보드가 열린다.

## 검증

- Windows Chrome에서 데스크톱 1370픽셀, 모바일 390픽셀과 320픽셀을 검증했다. 화면 폭, Registry 검증·재열기, 노드 선택, 실제 앱 준비·종료, 스위트 사전 점검 차단, 정상 스위트 실행, 보고서 경로 복사, 새로고침 후 결과 복원을 확인했다.
- JavaScript 테스트 8개가 통과했다. Windows Python 회귀 테스트는 144개가 통과했고 선택 실행 테스트 8개는 건너뛰었다. 스위트 파일 선택 검사를 추가한 뒤 웹 API 테스트 21개가 모두 통과했다.

## 재개 지점

macOS 기본 선택 창과 모바일 원격 미리보기에서 대시보드를 확인한다. 런타임 결과 분류는 [T-380](T-380.ko.md)에서 이어간다.
