## 1. Design

Use macOS as primary and support the same prepare, stop, hosts CLI, UI, and registry on Windows. Finder uses a `.command` and Windows uses VBS. Both favor the project venv. On macOS, run hosts changes with elevation, preserve file ownership and permission metadata, and replace within the same filesystem. Windows uses ReplaceFileW. Both share locking and ownership checks.

## 2. Development

Added executable LF `Start-Injector.command` with ARM and Intel Homebrew and Docker lookup. macOS hosts uses locking and `cp -p` to preserve metadata. Runner paths share the same resolution rules. POSIX processes run in a separate session. The loopback server skips reverse lookup. CI runs Python 3.10 on macOS ARM64 and Windows x64 and checks spaced macOS launcher paths. [Apple cp](https://github.com/apple-oss-distributions/file_cmds/blob/main/cp/cp.1)
