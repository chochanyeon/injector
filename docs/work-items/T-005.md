## 1. Design

Help LLMs discover apps, endpoints, hosts, ports, injection keys, and transitive dependencies. Record file and line evidence, inferences, local proposals, and unknowns without copying credentials. The draft is separate from runtime configuration. Conversion is tracked in T-100.

For a first registration, identify candidates, then investigate the target app, infrastructure, and cross-app edges. Register and verify one target and its dependency subgraph before expanding. For Spring, compare configuration files, runtime inputs, and source consumers for the selected runner.
