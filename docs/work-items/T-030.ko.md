## 1. 설계

관련: R-01, R-02, R-08, D-07. 검증된 등록에서 특정 노드의 설정을 계산하는 순수 메모리 해석기를 추가한다. 앱에 값을 전달할 준비 결과까지 생성하고 실제 프로세스·IntelliJ 실행 연결은 T-050·T-060에서 수행한다.

### 1.1. 합성과 충돌 정책

공통 `defaults` → 프로필이 선택한 variant → 프로필 `overrides[node]` 순서다. env·vmProperties는 뒤의 값을 적용하고 최종 출처를 기록한다. vmOptions는 배열 순서대로 연결하고 각 항목의 출처를 기록한다. 임의 JVM 플래그의 의미를 분석하거나 중복 옵션을 자동 정리하지 않는다.

의존성 `injections`는 합성 후 추가한다. 이미 수동 설정이 있거나 다른 주입이 같은 채널·키를 사용하면 값이 같아도 충돌로 거부한다. 자동 주소와 수동 주소 중 하나를 조용히 선택하지 않기 위해서다. env와 VM 시스템 속성은 별도 채널이며 프레임워크의 우선순위를 도구가 추정하지 않는다.

`fromEnv`는 최종 선택된 값만 조회한다. 상위 레이어가 덮어쓴 참조는 읽지 않는다. 필요한 참조가 없으면 실패하며 실제 값은 오류에 포함하지 않는다. 개인 설정은 이 환경 참조로 공급하고 별도 개인 설정 파일은 추가하지 않는다.

### 1.2. 접속 정보

주입 source의 node·endpoint·context로 선택한 의존 variant의 주소를 찾는다. host·container context를 임의로 대체하지 않으며 바인딩 주소를 호출 주소로 사용하지 않는다. host·port는 개별 문자열, url은 `scheme://host:port/path`로 계산한다. IPv6는 URL authority에서 대괄호로 감싸고 경로의 한글·공백을 인코딩한다.

와일드카드 수신 주소, 자격증명이나 URL 전체를 넣은 hostname, URL scheme 누락·HTTP 프로토콜 불일치, path에 넣은 query·fragment를 거부한다. scope ID가 있는 IPv6와 JDBC 같은 별도 접속 문자열 문법은 현재 해석 범위가 아니다. 논리 hostname의 실제 해석·등록은 T-070에 남긴다.

### 1.3. 출력과 런타임 경계

`resolve_node`는 실제 env·VM 옵션·시스템 속성과 출처를 담은 `ResolvedSettings`를 반환한다. `jvm_arguments()`는 shell 문자열이 아닌 JVM 인자 배열을 만든다. NUL 문자는 런타임에 넘기기 전에 거부한다.

`describe()`와 객체 repr은 실제 값을 출력하지 않는다. literal에도 비밀값이 있을 수 있으므로 CLI resolve는 모든 값·raw 옵션을 가리고 키·출처·옵션 인덱스만 제공한다. 실행 어댑터는 메모리의 실제 값을 사용해야 하며 이 진단 출력을 설정 파일로 사용하면 안 된다.

CLI는 `resolve --project <디렉터리> --profile <이름> --node <ID>`다. 검증 후 설정을 해석할 뿐 파일을 쓰거나 앱을 실행하지 않는다.

## 2. 개발

- [resolution.py](../../injector_core/resolution.py): variant 선택, 주소 계산, 설정 합성, 출처·충돌·환경 참조 처리.
- [injector.py](../../injector.py): resolve 진단 명령. 기존 데모 명령과 validate는 유지.
- [test_resolution.py](../../tests/test_resolution.py): 주소·합성·충돌·비밀값·비변경 검증 13개.

현재 해석기는 검증된 dict를 입력으로 받는다. 일반 등록의 XML 생성·프로세스 실행은 이 작업에서 연결하지 않았다.

## 3. 검증

2026-11-17에 `python -m unittest discover -s tests -v`로 총 38개 통과를 확인했다. T-030의 13개 테스트에서 다음을 확인했다.

- 실제·대역 및 호스트·컨테이너 주소 선택, host·port·URL 주입.
- 공통·variant·프로필 덮어쓰기와 최종 출처, 공백·인용부호·한글·줄바꿈 값 보존.
- 누락 환경 참조, 덮어쓴 참조 무시, 수동/자동 키 충돌, 중복 주입.
- IPv6 URL과 경로 인코딩, 잘못된 URL·hostname·와일드카드·NUL 거부.
- 실제 비밀값·literal·raw VM 옵션이 CLI·describe·repr에 나타나지 않음.
- 원본 등록을 변경하지 않으며 CLI에서 subprocess를 실행하지 않음.

`python injector.py resolve --project examples/registry --profile local-real --node catalog`도 확인했다. DNS·실제 앱 주입·Docker·IntelliJ 통합 검증은 이번 작업의 범위가 아니다.
