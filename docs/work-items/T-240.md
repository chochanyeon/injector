# T-240. Remember the selected project and registry

**English** · [한국어](T-240.ko.md)

[Work index](../index.md) · Prerequisite T-200

## 1. Design

Store the last successfully loaded source folder and registry path together in Injector's Git-ignored local storage. Restore both on a normal web launch. An explicit CLI source selection takes precedence. Loading the restored paths never starts services. A missing path stays visible for correction. A failed load or cancelled picker preserves the saved selection.

## 2. Development

An authenticated project load validates both paths and atomically replaces `.local/web-selection.json`. The browser uses it after changing a path with the picker or pressing Load. Browser startup reads the saved pair through `/api/info`. If the preference cannot be saved, the browser can still load the project and displays the persistence issue.

## 3. Verification

The HTTP regression starts fresh servers against the same preference file. It checks restoration, explicit startup inputs, missing files, malformed preferences, job state, token enforcement, and preservation after a failed load. Headless browser tests cover manual load, picker load, and read-only fallback. On Windows, 113 Python tests and five web tests passed. Six opt-in Python tests were skipped.
