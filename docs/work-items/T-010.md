## 1. Design

Related requirements R-08–R-11, design sections 15–16, and decisions D-02–D-07. Start with JVM/IntelliJ, local processes, and Compose. Use JSON v1.0 and Draft 2020-12 with `jsonschema==4.26.0`. Legacy `project.json` and draft v0.1 remain separate contracts.

| Field | Meaning |
|---|---|
| `schemaVersion` | Exactly `1.0` for this contract |
| `nodes` | IDs, kind, and named variants. IDs start with a lowercase letter and can contain lowercase letters, digits, and hyphens. |
| `kind` | `application` or `infrastructure` |
| `execution` | `process`, `intellij`, `compose`, or `external` |
| `endpoints` | Per-node names, protocol, bind address, and caller-specific addresses |
| `dependencies` | Ordered unique IDs for the variant |
| `readiness` | HTTP, TCP, or Compose healthcheck with a timeout |
| `injections` | Dependency endpoint to environment key or JVM property |
| `profiles` | App `targets`, variant `selections`, and optional `overrides` |
| `defaults` | Shared environment and JVM settings, empty when omitted |
| `nameMappings` | Name, address, and `hosts` or `external` method |

Node and endpoint IDs are logical. Real and mock variants can have different dependencies. Shared infrastructure has one ID. Every required node needs an explicit selection.

Process execution uses a `command` argument array and `workingDirectory`. IntelliJ uses `projectPath`, `module`, and `mainClass`. Compose uses `file`, `service`, and explicit `projectName`. External resources require readiness. Paths are source-root-relative, with existence checked before execution and containment in T-020. The bind address is separate from host and container caller addresses. URLs use a scheme and optional path. Injection identifies `node`, `endpoint`, `context`, and `component` (`url`, `host`, or `port`).

Layer defaults, selected variant, and profile override in that order. Later maps replace matching keys and JVM flags concatenate. Put JVM flags in `vmOptions`, named `-D` values in `vmProperties`, and private values behind `fromEnv` references. The schema rejects required nulls, unknown fields and versions, and raw `-D` flags. Omitted optional settings are empty. Keep credentials out of literals. Structural checks belong here. T-020 checks references, T-030 handles injection conflicts, and T-040 handles cycles and ordering.

## 3. Verification

All 10 tests passed on November 17, 2026, including 8 schema tests. `Draft202012Validator.check_schema` verified the schema. Tests cover invalid versions and fields, draft and legacy rejection, nulls, ports, runner fields, raw `-D` options, and empty secret references. Reference, runtime, and DNS verification are separate.
