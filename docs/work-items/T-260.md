# T-260. Observe and compare one local HTTP dependency

**English** · [한국어](T-260.ko.md)

[Work index](../index.md) · Prerequisite T-250

## Design

Use one HTTP JSON scenario and one direct outbound dependency registered as a host URL injection. Injector owns the scope and lifetime of the local recording; Verifier compares artifacts. The artifact records the selected logical edge, profile, scenario, target response and observed calls. Only explicitly selected scalar JSON fields are captured.

## Development

`observe-http` prepares an isolated session, redirects one configured host HTTP URL through a loopback proxy, runs the scenario, and stops the session. `compare-http` delegates to Verifier. The browser sends the two artifacts to the same comparator and highlights the logical graph edge when the active profile and its edge variants match. The artifact keeps the schema version, scenario fingerprint, and coverage evidence. [Schema](../../schemas/http-observation-v1.schema.json) · [Demo](../../examples/demo/http-observation/README.md)

## Verification

The CLI regression showed that both target responses returned 201 while a downstream request field changed. It checked PASS, FAIL, INCONCLUSIVE, active session preservation, and cleanup. The HTTP API preserved large integers. In a headless Edge browser, both files rendered side by side and the corresponding graph link was highlighted. On Windows, 128 Python tests and six web tests passed. Six opt-in integration tests were skipped.
