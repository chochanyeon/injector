# T-260. Observe and compare one local HTTP dependency

**English** · [한국어](T-260.ko.md)

[Work index](../index.md) · Prerequisite T-250

## Design

Use one HTTP JSON scenario and one direct outbound dependency registered as a host URL injection. Injector owns the scope and lifetime of the local recording; Verifier compares artifacts. The artifact records the selected logical edge, profile, scenario, target response and observed calls. Only explicitly selected scalar JSON fields are captured.
