## 1. Design

Serve the HTML, CSS, and JavaScript through a Python standard-library HTTP server on `127.0.0.1:18770` to control local Docker and processes. Windows starts through pythonw. Install Python dependencies once.

The UI loads a project, selects a profile and app, shows DFS, runs prepare, shows progress, provides Debug instructions, and offers stop. Browser close preserves the server and resources. Run one prepare or stop at a time in a worker. Restrict Host to loopback and protect mutating requests with a token and same-origin checking. Static assets are allowlisted, CORS stays closed, and results omit settings. This is a local single-user control surface.

## 2. Development
