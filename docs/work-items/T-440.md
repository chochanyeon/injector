# T-440 · Validate and repair injection rules

**English** · [한국어](T-440.ko.md) · [Work index](../index.md)

## Design

Detect conflicts in each reachable profile before saving. Identify the profile, node, channel and key without resolving environment values. Allow a user to inspect, replace or remove a single existing rule in a node draft and preserve the existing save and concurrency checks.

## Development

- Registry validation and runtime resolution share settings precedence and injection key checks. A conflicting manual setting reports its effective layer. A duplicate rule identifies the earlier rule index.
- The node editor preselects the stored rule's source and channel. Replacing a rule retains its position. Endpoint suggestions use the profiles whose targets actually reach the caller. When a profile plan is incomplete the editor conservatively considers its selections so the draft can still be repaired.

## Verification

The original demo accepted a shared environment setting for `VAULT_ADDR` and failed during runtime resolution. The HTTP regression covers rejecting a conflicting profile override, locating its origin, repairing the rule and saving. Windows Chrome verified adding, editing, and deleting a Vault injection in the draft. The Windows launcher also passed shutdown and restart with a running dependency. The Windows regression run passed 149 Python tests with eight optional integration tests skipped. All eight JavaScript tests passed.
