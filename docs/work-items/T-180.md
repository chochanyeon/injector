## 1. Design

Show all apps selected in the current profile, or the reachable subgraph for a chosen app. Include the variant, runner, and app or infrastructure kind. Edges point from consumer to dependency. Share nodes across paths. Readiness stays in the execution plan and invalid graphs display errors. Use layered placement and highlight direct edges. [Eclipse ELK](https://eclipse.dev/elk/blog/posts/2025/25-08-21-layered.html) · [React Flow edges](https://reactflow.dev/examples/edges/edge-types)

## 2. Development

`GET /api/graph` reuses registry validation and DFS and returns graph metadata. HTML nodes and Canvas edges support shared nodes, column-spanning arrows, scrolling, and a text list. Highlight direct incoming and outgoing relationships without reflow. Refresh after profile change or registry save. Graph, plan, and logs can collapse independently. Added `support-console` sharing Catalog and Vault with platform-service. Real Catalog adds PostgreSQL.
