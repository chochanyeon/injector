# T-270. Multi-service shop monorepo demo

**English** · [한국어](T-270.ko.md)

[Work index](../index.md) · Prerequisites T-110 and T-260

## Design

Add an isolated JVM multi-project example under `examples/demo/monorepo/`. A checkout traverses several HTTP services, stores orders and stock in PostgreSQL, caches catalog data in Redis, and delivers an event through Kafka. Pricing has a real database-backed variant and a WireMock variant.

## Development

The root Gradle build contains six runnable app modules and one shared library. The file-per-node registry selects database-backed pricing in `real` and a WireMock service in `mock`. Both profiles use a shared order and inventory database, Redis, and Kafka. A quote scenario records the Storefront-to-Catalog HTTP edge. [Run the demo](../../examples/demo/monorepo/README.md)

## Verification

Windows Gradle `installDist` built all applications. The opt-in test passed against Docker Desktop and the JVM. Both profiles returned the expected price and checkout total, reused an order ID without reducing stock again, rejected insufficient stock, recorded Redis cache hits, and delivered the Kafka event. HTTP observation captured the price from WireMock. The test used isolated ports and removed its containers and network.
