## 1. Design

Start after deciding D-01 and verifying the base pipeline. Consider invoking prepare before Run or Debug, propagating cancellation and failure, and avoiding duplicate startup. A plugin is one possible implementation. Acceptance requires failed preparation to block the selected IDE launch flow. [Design](../design.md)

## 2. Development

Scope, timing, and implementation remain open. Record relevant changed files and behavior once work starts.

## 3. Verification

Planned checks cover ordinary preparation, preparation failure, cancellation, and repeat execution. Record command, environment, and outcome.

## 4. Resume point

Resolve D-01 and select the first IDE workflow to verify.
