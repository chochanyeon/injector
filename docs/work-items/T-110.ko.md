# T-110. 다중 앱 통합 검증

[English](T-110.md) · **한국어**

[작업 인덱스](../index.ko.md) · 선행 작업 T-060~T-100

## 1. 설계

`examples/demo/multi-app/`의 독립 샘플로 SQLite를 공유하는 두 앱, 주입한 주소로 앱 간 호출, mock 전환, 사용자 지정 호스트 이름 불일치, 시작 실패 후 롤백을 검증한다. 임시 소스 폴더 두 곳과 검토한 Registry 후보를 사용한다. 기존 Docker와 JVM 데모는 별도로 검증한다.

## 2. 개발

`tests/test_multi_app_integration.py`가 초안을 외부 Registry로 변환한다. 실제 실행 엔진으로 서비스를 시작하고, 대상 앱을 호출하고, 종료와 데이터 보존을 확인한다.

## 3. 검증

Windows 통합 테스트 두 개가 통과했다. real에서는 한 SQLite DB에 두 앱의 쓰기가 남았고 두 번째 소스 폴더에서는 mock 호출에 성공했다. Catalog 시작 실패 후 DB 서비스를 종료했고 데이터는 보존됐다. 사용자 지정 이름 테스트는 다른 주소를 반환하는 리졸버를 모의해 기동 전 실패를 확인했다.

## 4. 재개 지점

실제 업무 프로젝트와 macOS에서 사용자 지정 호스트 이름 해석 및 IntelliJ Debug를 검증한다.
