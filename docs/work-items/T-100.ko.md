# T-100. LLM 등록 초안의 검증·변환

[English](T-100.md) · **한국어**

[작업 인덱스](../index.ko.md) · 선행 작업 T-020, T-040

## 1. 설계

버전 0.1 초안은 값이 미해결이어도 검토할 수 있다. 변환에는 확정된 단일 프로필, 도달 가능한 노드와 연결별 근거, 실행 설정, 기대 순서가 필요하다. 기존 실행 파일의 변경은 사용자가 검토한 뒤 적용한다. 변환 과정에서 앱이나 hosts 설정을 변경하지 않는다.

## 2. 개발

`draft-check`는 구조, 참조, 차단 항목을 확인한다. `draft-convert`는 소스의 근거 파일과 줄을 확인하고, 확정된 그래프를 스키마 1.1로 변환한다. 계획 순서와 호스트 포트 충돌을 검증한 뒤 새 후보 파일을 쓴다. 등록 프로토콜에 실행 방식과 주입에 필요한 필드를 기록했다.

## 3. 검증

Windows에서 변환 테스트 네 개가 통과했다. 유효한 그래프와 기존 출력 보존, 미확인 필수값, 근거 누락, 순환, 포트 충돌, 인코딩 실패 시 후보 파일이 생성되지 않는 것을 확인했다. 공개된 예시 초안의 차단 항목 두 개를 CLI에서 확인했다. 스킬 형식 검사와 설치본의 변경 파일 네 개 해시 비교도 통과했다.

## 4. 재개 지점

업무 저장소의 검토한 초안으로 조사 근거, 실행 후보, 실제 기동 결과를 비교한다.
