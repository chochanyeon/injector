# T-430 · Shut down the web server from the dashboard

**English** · [한국어](T-430.ko.md) · [Work index](../index.md)

## Design

- Add a confirmed server shutdown action to the desktop dashboard. Use the existing local control token and close the listening server after responding.
- Reject shutdown during a background job or an open system picker. Preserve running dependencies and the persisted registry selection.

## Development

- The [dashboard](../../injector_core/web/index.html) confirms shutdown and shows when the server has stopped. The [HTTP handler](../../injector_core/web.py) protects shutdown with the existing local token, rejects it during jobs and open native pickers, and prevents new jobs or writes after shutdown starts.
- The request acknowledges shutdown before stopping the serve loop so the launcher exits normally. The existing dependency stop action still owns resource cleanup.

## Verification

- The web tests verified the control token, origin check, conflicts with an active job or picker, serve loop exit, and port reuse.
- Windows Chrome and `Start-Injector.vbs` verified canceling, shutting down, restarting, and retaining a managed dependency across the restart. The launcher ran from a temporary copy on a separate port.
- Windows regression passed 148 Python tests and eight JavaScript tests. Eight optional Shop and WireMock integration cases were skipped.
