# T-310. 두 워크트리의 HTTP 시나리오 비교

[English](T-310.md) · **한국어**

[작업 인덱스](../index.ko.md) · 선행 작업 T-260, T-300

## 설계

이미 존재하는 두 워크트리에서 같은 대상과 프로필로 시나리오를 차례로 실행한다. 중앙 레지스트리 하나를 함께 사용할 수 있다. 기존 기록기, 파일 형식, Verifier를 재사용하므로 나중에 웹에서도 두 기록을 비교할 수 있다. 시작 전에 두 실행 계획과 활성 세션을 확인하고 각 실행의 세션 소유권 검사도 유지한다.

실제 Git 워크트리 간 비교, 두 실행의 정리, 활성 세션과 기존 출력 폴더의 보호를 완료 기준으로 삼는다.

## 개발

`compare-worktrees` 명령은 시나리오를 한 번 읽고 양쪽의 선택된 연결과 활성 세션을 확인한다. 새 출력 폴더에서 기존 기록기를 각 워크트리에 적용하고, Verifier 결과와 기록 파일 경로를 출력한다.

## 검증

- Windows에서 HTTP 관측 테스트 여섯 개가 통과했다. 동일 결과, 하위 요청 필드 변화, 같은 포트 재사용과 정리, 활성 세션과 기존 출력 폴더 보호를 확인했다.
- 임시 Git 저장소에서 실제 워크트리 두 개와 공용 레지스트리로 검증했다. 후보의 하위 요청 창고 값만 바꾸자 양쪽 대상 응답은 같았고 Verifier가 변경 필드를 찾았다. 두 세션 모두 종료됐다.
- 기본 Python 테스트 135개가 통과했고 별도 설정이 필요한 7개는 건너뛰었다.
