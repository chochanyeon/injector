# T-400 · Run and inspect local work in the web dashboard

**English** · [한국어](T-400.ko.md) · [Work index](../index.md)

## Design

Keep project and registry selection visible. Present execution status and the active target's dependency graph together with paths to inspect the details. Make suite preflight and execution available through the same Verifier logic as the CLI. Check narrow and desktop layouts, registry editing, and the prepare and suite flows.

## Development

- The [dashboard](../../injector_core/web/index.html) separates project selection, execution progress, dependency inspection, and verification. The graph opens for the selected app and supports an all-app view.
- The [web controller](../../injector_core/web.py) uses the same suite check and runner as the CLI. It saves evidence under `.local/verification/`. The browser shows case results, copies the report path, and restores the latest suite for the same project when reloaded against the same server.
- The Registry dialog keeps the editor and its actions visible in narrow viewports. On touch layouts, users tap the text area when they want to open the keyboard.

## Verification

Browser checks covered layout width, Registry validation and reopening, dependency selection, a real prepare and stop, a blocked suite preflight, a successful suite, copying its report path, and restoring its result after a reload.
