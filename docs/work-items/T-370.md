# T-370 · Verify required and forbidden event counts

**English** · [한국어](T-370.ko.md) · [Work index](../index.md)

## Design

Let a scenario specify how many times a correlated event can occur. A rejected request can require zero Kafka events. A single checkout can require one publish and one consume. Use the existing trace selectors and require a configured settling window before checking counts.

- A confirmed count mismatch fails a scenario even when both versions have that count.
- Incomplete or unavailable trace evidence yields `INCONCLUSIVE` for the count check.
- Existing scenarios preserve their trace behavior.

## Development

- Add `trace.eventCounts` and `trace.settleSeconds` to the [scenario and artifact schema](../../schemas/http-observation-v1.schema.json). Each count check has a unique check ID and selector. Preflight rejects a required event with a zero count.
- The [Loki recorder](../../injector_core/trace_observation.py) restarts the settling timer when events change or queries fail. It records the expected count, observed count, and verdict. Count checks can serve as a named `proveFix` check.
- The [checkout case](../../examples/demo/monorepo/scenarios/checkout-evidence.json) requires one publish and one consume. The [rejected checkout case](../../examples/demo/monorepo/scenarios/checkout-invalid-quantity.json) requires zero of each.

## Verification

- Trace tests covered duplicate publishes, a publish arriving after the original 0.75-second settling time, incomplete logs, and a contradictory scenario that requires an event and forbids it. The shared schema passed JSON Schema validation.
- The Windows Docker and JVM suite passed both cases. Both worktrees recorded one publish and one consume for checkout and zero of each for the rejected request. The Markdown report linked to both paired reports and all four recordings. No Injector-managed containers remained.
- The broader Windows run passed 147 tests, including Spring Boot and WireMock Vault. The two opt-in shop tests were skipped in that run. The direct shop suite covered the new Docker behavior.
