## 1. 설계

기존 Markdown 경로는 영어판으로 유지한다. 한국어판은 같은 폴더의 `*.ko.md`에 둔다. GitHub와 개발·스킬의 기존 진입 경로를 유지하고, 두 언어를 서로 연결한다. 문서 내부 링크는 선택한 언어의 문서로 이어진다.

## 2. 개발

README, 개발 지침, 설계·현황, 검증 이력, 작업 문서, 예제, 등록 스킬을 영어판으로 작성했다. 원래 한국어 내용은 대응 파일에 보존하고 양쪽 문서 관리 방식을 기록했다.

## 3. 검증

문서 38쌍, 상대 링크 472개와 Markdown 제목 앵커, 두 작업 인덱스의 연결을 확인했다. 저장소와 로컬 설치본의 등록 스킬 형식 검사를 통과했고, 데모의 `validate`와 dummy `plan`도 확인했다.
