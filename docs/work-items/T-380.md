# T-380 · Run registration and verification without manual prompts

**English** · [한국어](T-380.ko.md) · [Work index](../index.md)

## Design

An LLM can use a reviewed registry, scenario expectations, and checkout paths to complete a local verification run from the CLI. For a first registration, it uses source evidence and reports missing settings or decisions for review. Routine runs use the approved inputs to preflight, prepare the app and dependencies, reproduce the failure, verify the candidate and related behavior, and clean up. The web UI uses the same validation and execution paths.

- Preflight checks all cases before starting any app. It returns structured diagnostics that identify the affected case or node and the missing input or failed check.
- Normal execution returns a versioned result with a verdict, exit code, saved evidence paths, and separate details for input, startup, behavior, and cleanup failures. An LLM can select the next action from the result.
- A fresh agent can follow a repository runbook to prepare both shop checkouts from documented prerequisites and produce the same report without UI interaction. Business expectations and required secrets come from reviewed inputs.

## Development

The repository already has dependency evidence discovery, draft validation and conversion, `check`, and `verify-suite`. `verify-suite` accepts existing checkouts and writes JSON and Markdown evidence. The suite currently preflights during execution. Invalid inputs can return a text error without a JSON report. The demo build is a separate step. ## Verification

Planned. Check a valid suite, an invalid later case, a startup failure, a confirmed regression, and a successful fix. Verify that an agent can use the files and exit codes to identify the next action. Run the workflow on Windows and macOS.

## Resume point

Expose the existing suite preflight as a non-mutating command with structured diagnostics. Use the same preflight for execution and add the headless walkthrough after the result format is verified.
