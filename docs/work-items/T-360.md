# T-360 · Run a fix and its regression scenarios together

**English** · [한국어](T-360.ko.md) · [Work index](../index.md)

## Design

One reviewed suite lists scenarios for one target and profile. Each scenario uses the existing worktree comparison. A suite can include fix verification and normal parity checks. Preflight every scenario before starting the first one.

- Use a fresh Injector session per checkout and scenario. Use scenario checks to confirm fixture state.
- Continue after a completed behavior failure. Stop starting new cases after a run fails to complete. Retain finished evidence and list pending cases.
- Provide one verdict, case counts, and links to the paired reports. A suite passes only when every case passes.

## Development

- Add `verify-suite` and validate version 1 suite files through the shared [schema](../../schemas/http-observation-v1.schema.json). One suite runs up to 16 uniquely named cases in order.
- Reuse the [paired runtime](../../injector_core/observation.py) for each case. Persist the detailed report on an interrupted run and keep the interrupt exit status. The [suite runner](../../verifier/worktree_suite.py) writes `report.json` and `summary.md` with relative evidence links.
- Add the [checkout suite](../../examples/demo/monorepo/scenarios/checkout-fix-suite.json). The second case reuses the first order ID to check session isolation.

## Verification

- The real Windows Docker and JVM suite returned `PASS` for both cases. The first case reproduced the incorrect price and passed on the candidate. The second case returned HTTP `400` on both sides. The candidate's initial and final stock were both 10. No order or delivery was present after rejection.
- Process tests check a later case's preflight failure, continuation after a behavior difference, fresh counters in every session, and reports after a startup failure or interrupt.
- The Windows regression run passed 141 tests, including Spring Boot. It skipped seven opt-in Docker tests. The direct shop suite covered Docker in this change.
