## 1. Design

Related requirements R-01, R-02, and R-08 and decision D-07. Resolve one validated node in memory. Layer shared `defaults`, the selected variant, and profile `overrides[node]`. Later map entries win with provenance, and `vmOptions` concatenate in order. Apply `injections` after merging. Reject duplicate channel and key use by manual settings or multiple rules. Read only effective `fromEnv` references and reject missing variables without exposing values.

Use the variant's explicit node, endpoint, and caller context. Return host or port as strings and assemble `scheme://host:port/path` for URLs. Bracket IPv6 authorities and encode paths. Reject wildcard bind addresses, credentials or full URLs in a hostname, missing or inconsistent schemes, query or fragment in a path, and NUL settings. Scoped IPv6 and JDBC syntax are outside the initial resolver. DNS belongs to T-070.

`resolve_node` returns `ResolvedSettings`. `jvm_arguments()` produces an argument array. `describe()` and repr redact all actual values, including literal and raw JVM flags. Runtime adapters consume the in-memory result.
