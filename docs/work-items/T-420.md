# T-420 · Registry editor autocomplete

**English** · [한국어](T-420.ko.md) · [Work index](../index.md)

## Design

- Suggest existing unregistered node JSON files relative to the selected registry. Apply a selection to the root draft's `nodeFiles` array.
- In a declared node file, offer execution fields from the registry schema, registered dependencies, and injection sources from the selected variant's dependencies.
- Keep changes in the draft. Preserve unrelated JSON, retain text repair, and use the existing validation and revision-checked save.

## Development

- The token-protected [completion handler](../../injector_core/registry_completion.py) reads the selected registry schema. Root search stays within the registry folder, skips hidden, build, and linked directories, and checks candidate files against the node schema.
- The [editor controls](../../injector_core/web/index.html) apply a selection to one field. The server preserves the JSON text outside that field, including Spring numeric literals. Saving still validates the combined registry and checks the file revision.

## Verification

- Windows desktop Chrome registered a new node file from an external registry folder, then added a dependency and Vault port injection and edited the IntelliJ main class. It checked that disk contents changed only after Save.
- Web API tests cover token checks, registry scope, invalid and duplicate candidates, split versus inline nodes, schema-specific injection channels, and exact preservation of unrelated numbers.
- On Windows, 147 Python tests and eight JavaScript tests passed. Eight optional Shop and WireMock integration tests were skipped.
