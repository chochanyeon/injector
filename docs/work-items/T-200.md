## 1. Design

Store local registries under Injector's Git-ignored `registries/<repo-id>/`. Worktrees can share registry settings. `--project` selects source and `--registry` accepts an explicit file or a directory containing the default `registry.json`. Explicit files are validated as registry JSON regardless of name or extension. Resolve `nodeFiles` against the selected registry file's directory and execution paths against source. The source-root layout remains supported. External mode saves generated files under a path scoped to the registry file and worktree. Keep the existing session location for `registry.json`, whether specified by file or directory. Import the generated XML into IntelliJ. The running app and IDE manage their own writes.

## 2. Development

The source picker accepts a folder. The registry picker returns the selected regular file path. The browser uses that path for loading and editing. Typed registry directories remain supported. Loading checks registry validity. The UI suggests centrally stored default registries and uses the same source–registry pair in the editor, plan, graph, prepare, and stop. The installed registration workflow keeps its default locations for settings and investigations.
