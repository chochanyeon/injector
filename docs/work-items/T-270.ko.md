# T-270. 다중 서비스 쇼핑몰 모노레포 데모

[English](T-270.md) · **한국어**

[작업 인덱스](../index.ko.md) · 선행 작업 T-110, T-260

## 설계

`examples/demo/monorepo/`에 독립적인 JVM 멀티프로젝트 예제를 둔다. 주문 요청은 여러 HTTP 서비스를 거쳐 PostgreSQL에 주문과 재고를 기록한다. 카탈로그는 Redis에 캐시하고, Kafka를 통해 이벤트를 전달한다. 가격 서비스는 데이터베이스를 쓰는 real과 WireMock 대역을 제공한다.

## 개발

Gradle 빌드에 실행 가능한 앱 모듈 여섯 개와 공통 라이브러리 하나를 둔다. 노드별 Registry 파일에서 `real`은 DB 기반 가격 서비스를, `mock`은 WireMock을 선택한다. 두 프로필은 주문·재고 DB와 Redis·Kafka를 공유한다. 가격 조회 시나리오로 Storefront에서 Catalog로 가는 HTTP 호출을 기록할 수 있다. [데모 실행법](../../examples/demo/monorepo/README.ko.md)

## 검증

Windows에서 Gradle `installDist`가 모든 앱을 빌드했다. 실제 Docker Desktop과 JVM으로 두 프로필의 가격과 주문 합계, 동일 주문 재요청 시 재고 유지, 재고 부족 거부, Redis 캐시 적중과 Kafka 알림 도착을 확인했다. HTTP 관측은 WireMock 가격을 기록했다. 테스트는 별도 포트를 사용하고 자체 컨테이너와 네트워크를 정리했다.

## 재개 지점

macOS에서 같은 통합 테스트를 실행하고 실제 워크트리 비교를 검증한다.
