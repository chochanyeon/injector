# T-430 · 대시보드에서 웹 서버 종료

**[English](T-430.md)** · 한국어 · [작업 인덱스](../index.ko.md)

## 설계

- 데스크톱 대시보드에 확인 절차가 있는 서버 종료를 추가한다. 기존 로컬 토큰을 사용하며 응답을 보낸 뒤 서버를 닫는다.
- 백그라운드 작업이나 OS 선택 창이 진행 중이면 종료 요청을 거부한다. 실행 중인 의존성과 마지막 Registry 선택을 유지한다.

## 개발

- [대시보드](../../injector_core/web/index.html)에서 종료를 확인하고 서버 종료 상태를 표시한다. [HTTP 처리기](../../injector_core/web.py)는 기존 로컬 토큰을 확인하고, 작업이나 OS 선택 창이 진행 중이면 종료를 거부한다. 종료가 시작되면 새 작업과 저장 요청을 차단한다.
- 응답 후 웹 서버 루프를 끝내 런처가 정상 종료되도록 했다. 의존성 정리는 기존 의존성 종료에서 수행한다.

## 검증

- 웹 테스트에서 로컬 토큰과 Origin 검사, 작업·선택 창 진행 중 충돌 처리, 서버 루프 종료, 포트 재사용을 검증했다.
- Windows Chrome과 `Start-Injector.vbs`로 종료 취소, 종료, 재실행, 재실행 동안 관리 중인 의존성 유지를 확인했다. 런처는 별도 포트의 임시 복사본에서 실행했다.
- Windows에서 Python 회귀 테스트 148개와 JavaScript 테스트 8개가 통과했다. 선택 실행 항목인 Shop 및 WireMock 통합 테스트 8개는 건너뛰었다.
