## 1. Design

Related to R-11 and design section 16. Convert reviewed draft artifacts into the T-010 runtime format and update the registration skill. Preserve evidence, proposals, unknowns, and established user values. Required unknowns remain unresolved. Conversion has no app or hosts side effects. [Design](../design.md)

Version 0.1 discovery drafts remain reviewable with unresolved fields. Promotion requires one selected profile, evidence per reachable node and edge, resolved runtime choices, and a matching expected order. An existing runtime file stays under user control.

## 2. Development

`draft-check` reviews the structure, references and blocking findings. `draft-convert` resolves evidence locations within the source checkout, transforms the reviewed graph into schema 1.1, verifies the plan and host endpoint conflicts, and writes a new candidate. The registration protocol documents required runner fields and injection address components.

## 3. Verification

Three converter tests passed on Windows. They cover a valid graph, a blocked draft, unresolved settings, missing evidence, a cycle, a shared host-port collision, and preservation of an existing output. The CLI reported two blockers for the published illustrative draft. The skill passed `quick_validate.py`.

## 4. Resume point

Use a reviewed work-project draft to compare discovery evidence, the candidate registry, and a successful run.
