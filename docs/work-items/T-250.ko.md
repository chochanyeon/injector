# T-250. Injector와 Verifier 저장소 통합

[English](T-250.md) · **한국어**

[작업 인덱스](../index.ko.md) · 선행 작업 T-110

## 설계

Injector와 공용 스키마는 루트에 둔다. 기존 Gradle Verifier는 Git 이력과 함께 `verifier/`로 가져온다. 두 모듈은 각자의 기존 명령을 유지한다. T-260에서 Injector가 기록한 HTTP 관측 결과를 Verifier가 비교한다.

## 개발

원본 Verifier 저장소의 커밋된 `main`을 가져온다. Gradle 빌드와 테스트는 `verifier/`에서 실행한다.

## 검증

원본 Verifier 커밋 `35d48ab`이 가져오기 커밋 `ae47415`의 부모인지 확인했다. 문서를 수정하기 전 파일 트리는 원본과 같았다. Windows에서 JDK 25로 `verifier/`의 동작 테스트, 기준선 기록과 비교가 통과했다.

## 재개 지점

T-260에서 첫 HTTP 관측 결과 형식을 연결한다.
