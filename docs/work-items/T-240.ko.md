# T-240. 프로젝트와 Registry 선택 기억

[English](T-240.md) · **한국어**

[작업 인덱스](../index.ko.md) · 선행 작업 T-200

## 1. 설계

마지막으로 불러오는 데 성공한 소스 폴더와 Registry 경로를 Injector의 Git 제외 로컬 저장소에 함께 저장한다. 일반 웹 실행에서 두 경로를 복원한다. CLI에서 소스 경로를 명시하면 그 선택을 우선한다. 경로를 복원하는 과정에서 서비스를 시작하지 않는다. 경로가 사라졌으면 사용자가 고칠 수 있도록 표시한다. 불러오기 실패나 파일 선택 취소는 저장된 선택을 바꾸지 않는다.

## 2. 개발

토큰 인증을 거친 프로젝트 불러오기가 두 경로를 검증하고 `.local/web-selection.json`을 원자적으로 교체한다. 선택 창에서 경로를 바꾸거나 불러오기 버튼을 누르면 저장한다. 화면 시작 시 `/api/info`에서 저장된 경로를 읽는다. 저장할 수 없는 환경에서도 불러오기를 지원하고 저장 상태를 화면에 알린다.

## 3. 검증

HTTP 회귀 테스트는 같은 설정 파일로 서버를 새로 띄워 복원, 명시 경로, 사라진 파일, 손상된 설정 파일, 작업 상태, 토큰 검사, 불러오기 실패 후 기존 선택 유지를 확인한다. 테스트 DOM에서 직접 입력, 선택 창, 읽기 전용 요청으로의 복구를 확인한다. Windows에서 Python 테스트 113개와 웹 테스트 5개가 통과했고 선택 실행 Python 테스트 6개를 건너뛰었다.
