# T-260. 로컬 HTTP 의존성 하나 관측·비교

[English](T-260.md) · **한국어**

[작업 인덱스](../index.ko.md) · 선행 작업 T-250

## 설계

HTTP JSON 시나리오 하나와 호스트 URL로 주입하는 직접 의존성 하나를 사용한다. Injector가 로컬 기록의 범위와 수명을 관리하고 Verifier가 결과를 비교한다. 결과에 연결, 프로필, 시나리오, 대상 응답과 관측 호출을 기록한다. 본문은 명시한 스칼라 JSON 필드만 수집한다.

## 개발

`observe-http`는 전용 실행 세션을 마련하고 등록된 호스트 HTTP URL 하나를 루프백 프록시로 연결한다. 시나리오가 끝나면 세션을 정리한다. `compare-http`와 웹 화면은 같은 Verifier 비교기를 사용한다. 화면의 프로필과 연결 양끝의 variant가 관측과 일치하면 해당 연결을 강조한다. 결과에는 스키마 버전, 시나리오 지문, 관측 상태를 저장한다. [스키마](../../schemas/http-observation-v1.schema.json) · [데모](../../examples/demo/http-observation/README.ko.md)

## 검증

CLI 테스트에서 대상 응답은 둘 다 201이고 하위 요청 필드만 달라진 사례를 검출했다. PASS, FAIL, INCONCLUSIVE, 기존 세션 보존과 정리도 확인했다. HTTP API는 큰 정수를 정확히 전달했다. 헤드리스 Edge에서 두 기록이 나란히 보이고 대응하는 연결이 강조되는 것을 확인했다. Windows에서 Python 테스트 128개와 웹 테스트 6개가 통과했다. 선택 실행 통합 테스트 6개는 건너뛰었다.
