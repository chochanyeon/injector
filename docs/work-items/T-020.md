## 1. Design

Related requirements R-01 and R-08 and decision D-03. `python injector.py validate --project <directory> [--profile <name>]` reads UTF-8 `registry.json`. Relative CLI paths use the current directory. Paths inside the registry originally resolve against the target root. The selected profile limits profile-dependent checks, while structural checks, global IDs, variant dependencies, and readiness checks always run.

Reject duplicate JSON properties, nonstandard constants, invalid encoding or syntax, unsupported schema fields, duplicate node IDs, unknown targets and variants, missing selections, invalid readiness, invalid injection endpoint and context, and execution paths outside the root, including symlink escapes, drive paths, and UNC paths. An injection source must be a declared dependency. Execution file existence, port availability, DNS, credentials, and cycle handling are checked in later stages.

Success reports version, node count, and checked profiles. Validation errors exit 1, usage errors exit 2, and diagnostics omit values. Legacy demo commands retain their behavior.
