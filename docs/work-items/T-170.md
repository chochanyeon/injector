## 1. Design

Open and edit existing registry files, including malformed JSON. Use CLI parsing, schema and reference checks, and DFS cycle validation. Report syntax location and schema or reference errors. Revalidate before saving and check the open revision to protect external edits. Require a local control token for reads and writes.

The native picker opens on the server's desktop. Support worktrees at different paths and retain the path and draft on cancel. Ask before discarding edits.

## 2. Development

Added modal open, validate, save, reload, collapse, and close. Initially supported existing UTF-8 `registry.json` files up to 2 MiB. Replace atomically under lock and preserve permissions and CRLF. Refresh apps, profiles, and execution order after save. Compact layouts scroll the editor internally. Bad project paths return JSON and unreadable responses display HTTP status and route. Added native Windows and macOS pickers. The original picker required a registry in the selected folder. T-200 separates these inputs.
