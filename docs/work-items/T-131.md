## 1. Design

Related to R-13. Share one mock origin and identify services with `GET /v1/<mount>/data/<service-id>`. Orders and Payments have the same keys and distinct messages, usernames, and passwords. Unknown services return JSON 404. Default mount and service are `secret` and `orders`.

`--vault-service` enables the mock and chooses `VAULT_PATH`. Host and container paths match, with runner-specific `VAULT_ADDR`. IDs start lowercase and allow lowercase letters, digits, and hyphens. Reject paths, queries, newlines, uppercase, and empty input. Mappings are the source of service availability. The shared token and API coverage follow T-130. Paths identify data. Company SDKs and configurable lookup paths remain unverified.
