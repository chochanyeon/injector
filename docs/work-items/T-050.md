## 1. Design

Prepare process, Compose, and external nodes in DFS postorder. Preflight settings, executables, Compose services, and readiness. Process runners use an argv array, and JVM arguments require `java`. Distinguish HTTP 2xx, TCP, and Compose health. A premature exit or timeout fails the plan.

Treat occupied ports and existing Compose project/service conflicts as errors. Use `--no-deps` so Compose follows the registry graph. Persist PID and creation time or unique container labels. Keep argv and resolved values out of the manifest. Use a project lock for prepare and stop. Reprepare replaces the owned session, and failure rolls back new resources in reverse order. Preserve networks, volumes, and IDE-started apps.

Compose override files contain interpolation references. The Docker child environment supplies the values. Compose JVM merge, generated YAML in process or Compose runners, and process and Docker output in diagnostics are outside the initial support. [Compose up](https://github.com/docker/compose/blob/main/docs/reference/compose_up.md) · [psutil](https://psutil.readthedocs.io/stable/index.html)

## 2. Development
